# license
This is a very simple tool I use for creating license files. 

## How to use
You can create a license file by simply running
```
license <license>
```
You can see a list of all available licenses with
```
licenses --help
```
The licenses are detected in the `licenses` directory of the program.  
So to add a new license, simply place a template into this directory and
the program will pick it up automatically.
